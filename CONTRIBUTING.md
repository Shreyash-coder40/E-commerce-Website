# Contributing to NextShop

Thank you for your interest in contributing to NextShop! We welcome developer contributions to make this AI-powered e-commerce ecosystem even better.

## 🤝 Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## 🚀 How to Contribute

### 1. Report Bugs & Request Features
Before writing code, search our [Issue Tracker](https://github.com/Shreyash-coder40/E-commerce-Website/issues) to ensure the issue or feature hasn't been logged yet. If not, create a new issue using our structured templates.

### 2. Local Setup
1. Fork this repository and clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/E-commerce-Website.git
   ```
2. Set up your environment file:
   ```bash
   cp .env.example .env
   ```
3. Install dependencies and start the dev server:
   ```bash
   npm install
   npm run dev
   ```

### 3. Submitting Pull Requests
1. Create a branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Commit your modifications with clear descriptive messages.
3. Push your branch and open a Pull Request (PR) against our `main` branch.
4. Ensure your PR follows the provided [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md).

## 💻 Style Guide & Linting

- Follow TypeScript and Next.js best conventions.
- Format all source code pages using ESLint and Prettier.
- Make sure the project builds cleanly (`npm run build`) before pushing your commits.
